## Overview

- **Name**: Combo Configurator Dialog (OWL front-end)
- **Description**: OWL dialog component that lets a salesperson pick one item per product combo, optionally configure variants of the chosen item, and set the combo product quantity with a live price fetched from the server.
- **Location**: [`addons/sale/static/src/js/combo_configurator_dialog`](../../../addons/sale/static/src/js/combo_configurator_dialog) — 2 files, ~314 lines
- **Language**: JavaScript (Odoo 18.0 OWL 2 component, ES modules) and OWL XML templates
- **Purpose**: Client-side UI for configuring a combo product inside the Sale order flow. It opens a nested product configurator for configurable combo items, calls the JSON controller `/sale/combo_configurator/get_price` for quantity-based pricing, and hands the final selection back to its caller through `save` / `discard` / `close` props.
