## Overview

- **Name**: Product Configurator Dialog (sale)
- **Description**: OWL dialog component that lets a salesperson configure a product template's attribute combination, optional products and quantities before adding lines to a sale order.
- **Location**: [`addons/sale/static/src/js/product_configurator_dialog/`](../../../addons/sale/static/src/js/product_configurator_dialog) — 2 files, ~484 lines
- **Language**: JavaScript (OWL 2 component, ES modules) + OWL XML template
- **Purpose**: Client-side state machine for the sale product configurator. Holds the main product plus its optional/child products in reactive state, recomputes exclusions and combinations, calls the server JSON routes under `/sale/product_configurator/*` for pricing, variant creation and optional-product discovery, then hands the result back through `save` / `discard` / `close` props.
