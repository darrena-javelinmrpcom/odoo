## Notes for Higher-Level Synthesis

- Boundary code: HTTP and JSON entry points that translate browser requests into sale, product and payment model calls. Not domain-bearing on its own.
- The two configurator controllers (`combo_configurator.py`, `product_configurator.py`) share the same pricing and PTAL/PTAV helper pattern and belong together with the product configurator component.
- `portal.py` is the integration seam with the payment module (`addons/payment`) and the portal module (`addons/portal`). Treat `CustomerPortal` and `PaymentPortal` as belonging to the sale-order portal component rather than to the configurator component.
